# Rust 桌面链接与文件服务

`crates/memokeep-desktop-services` 是独立于 Tauri 的共享服务，宿主命令在 `crates/memokeep-tauri` 注册。页面继续使用原有链接菜单、链接卡片、文件预览和知识库导入界面。安装包不启动 Node 服务。

## 链接预览

`link_preview::fetch(database, url, refresh)` 返回 `title / description / site / image`。支持 Open Graph、Twitter、网页标题和描述的回退、相对图片 URL 及网页声明的字符编码。普通读取复用有效缓存；菜单「重新获取网页信息」明确传递 `refresh: true` 并重新联网。刷新失败会显示错误，保留原卡片，不以旧缓存报告刷新成功。

只接受 HTTP(S) 且不含账号的 URL。每次连接使用同一次 DNS 查询的全部地址检查结果，拒绝本机、私有和保留网络；重定向逐跳复核，不使用系统代理。TLS 证书正常校验。网络预算为 10 秒、正文最多 2 MiB、重定向最多 5 次，并发最多 4 个；请求声明 identity，压缩响应明确拒绝。桌面封面经独立 Rust 入口执行同样的公网检查、逐跳复核和总网络预算；仅接收不超过 512 KiB、单边不超过 4096 且总像素不超过 1600 万的 PNG/JPEG/GIF/WebP，签名与 MIME 必须一致。WebView 只显示验证后的 data URI，不自行解析封面域名；共享正文继续保存原图片 URL。序列化使用 inert 文档，避免保存时给活跃 Image 赋远端 URL 而触发旁路请求。普通浏览器模式和其他普通笔记图片不是这条 Rust 封面代理的范围。

缓存保存在工作空间 SQLite 的 `desktop_link_preview_cache`，1 小时过期、最多 100 条。网页内容不长期驻留进程内存；缓存不是业务数据，不进入便携备份或外部提交记录。

## 系统文件打开

宿主接收启动参数、macOS `RunEvent::Opened` 和主窗口原生拖入，仅支持 `.md / .markdown / .txt`。限制为单文件 5 MiB、严格 UTF-8（可含 BOM），失败按文件分别反馈。持久待处理队列最多 256 个普通项，溢出时另保留一条去重提示，未接收的源文件保持不变、需用户处理当前队列后重新打开；单次 IPC 返回有总量限制，不把所有文件长期驻留内存。

系统打开沿用原来的行为：优先定位已经存在的笔记，否则导入当前知识库。拖入窗口沿用预览、编辑、保存知识库和原目录另存的流程。没有知识库、保存失败或取消未保存确认时，待处理项继续保留；业务保存成功后才确认队列。稳定事件 ID 防止保存成功、确认前退出造成重复导入。

`desktop_file_*` 表只保存设备本地队列、路径授权和覆盖确认。前端接收不透明 token，不接收绝对路径，也不能通过 IPC 指定任意读写目录。普通浏览器 File 可预览和导入，不能获得本机原目录写权限。待处理权限在队列确认后保留 24 小时；跳过或关闭预览可主动撤销。

桌面桥仅在 macOS 桌面环境以 `nativeDocumentDrop: true` 声明文档拖入由原生队列独占接收；Windows、Linux 和普通浏览器保留 File 预览和知识库保存。平台声明只控制 UI 路由，不授予文件权限。相同手势即使同时产生 DOM 和原生事件，macOS 的 DOM 路径也不读取 `File`、不创建无授权预览或第二份副本；图片事件继续交给图片编辑器。若 DOM 事件先到，页面提示等待系统读取；5 秒仍未收到相应原生项时明确报错并保留当前内容，迟到的持久队列仍可接收。原生 `workspace-file-error` 会立即清除等待和拖入遮罩，以有长度限制的纯文本提示错误，不确认队列、不撤销现有授权或改动未保存内容。等待提示只按文件名对应 UI 状态，不据此授予文件权限。现有预览中的编辑以及保存中暂不能接收的持久项都不会被 DOM 副本替换。

原目录另存按授权的目录句柄执行，拒绝路径穿越、符号链接和目录身份置换，使用同目录临时文件和原子替换。新文件不能覆盖已有目标；目标已存在时，先由原生对话框明确确认，再复核目标指纹和一次性确认凭据。发布前先持久记录本机保存意图，文件发布后再补回执。若文件已写入但 SQL 回执失败，返回“已保存、回执待补记”；相同请求重试仅核对原始字节哈希并补记，不再次替换文件，外部改动会明确冲突。文件系统保存与 SQLite 的权限记录不构成跨文件系统原子事务，不把它描述成业务 SQLite 的整体回滚。覆盖前的指纹检查与最终 rename 也不是对任意外部编辑器的通用 CAS。

macOS 安装包以 `Alternate` 声明三种扩展名，作为可选打开方式；应用不会主动修改用户已有默认应用。

## 验证

```sh
cargo clippy --locked -p memokeep-desktop-services --all-targets --all-features -- -D warnings
cargo test --locked -p memokeep-desktop-services --all-features
npm test
```

HTTP 测试只在 `cfg(test)` 内使用本机测试解析器，产品入口固定使用公网解析器，不提供放行私网的配置。文件测试使用临时目录，覆盖持久化、错误隔离、授权边界、覆盖确认和发布文件定位。系统通知、扫码等其他能力的验证范围不由这些测试替代。
